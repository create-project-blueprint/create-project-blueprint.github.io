Frequently Asked Questions

🔐

How secure is my data?

This site is a project information hub. For details about a particular service or account, check that service’s own privacy information; this page does not claim end-to-end encryption for the whole project.

🐕‍🦺

What services do you offer?

CPB is a community-run modded Minecraft project. The site documents its history, seasons, member projects, governance, and community information; it is not a paid software service.

📱

Is there a mobile app?

There is no official CPB mobile app listed here. Use this website and the community Discord for current project information.

🌍

Where are your servers located?

This website is hosted on GitHub Pages. Minecraft server availability and hosting details are separate and are not currently published as an active server address.

💳

Is there an application fee?

Start with the CPB Discord application. The community can share the current requirements and next steps there. Joining the Discord does not mean a Minecraft season is open.

🔄

Is CPB currently in a playable season?

The history page records Season 3.1 as a past chapter that went offline after hardware failures. CPB Season 1 is in development; no launch date is posted.
